# Pleh Documentation

Pleh is a small Haskell project for representing, evaluating, and exploring propositional logic formulas.

The documentation is divided by topic:

- [Overview and usage](overview.md)
- [Formula syntax](formulas.md)
- [Typing judgments](typing.md)
- [Semantics and evaluation](semantics.md)
- [Logical properties](properties.md)

The implementation makes the connection between Haskell's type system, inductive data structures, and the semantics of propositional logic explicit.
